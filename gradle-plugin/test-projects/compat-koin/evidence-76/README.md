Group E on iosArm64, **compile only** (`E-iosArm64-compile-only.txt`): the device toolchain's kotlinc-native
(2.5.255-SNAPSHOT) with `-Xplugin=koin-compiler-plugin-1.2.3.jar` builds the group E Koin module into an ios_arm64 klib
(exit 0). The 2.4.20 adapter does not crash; its only output is the version warning, recorded verbatim. The klib holds
the plugin's generated module (`buildFactory` GreeterImpl -> Greeter, `buildSingle` Extra, `startKoinWith`), which a
build without the plugin lacks (11666 vs 14902 bytes). **Compile success is not the same as starting on a device:**
nothing was linked, signed or run on an iPhone, and the device pipeline (device/b1, device/b4) does not pass the
project's compiler plugins yet.

Open (not a #76 change): after a HOT patch of the file that declares an interface and its Koin-created implementation,
the app sometimes ends with `ClassCastException` (step c4 of B, D, E: rc-B 67, rc-D 67, rc-E 59). Reported to the
hot-reload line (LIMITATIONS 21).
