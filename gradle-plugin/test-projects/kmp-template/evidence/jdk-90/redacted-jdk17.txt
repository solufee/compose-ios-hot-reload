# Issue #90: a wizard-template project with dev.zacsweers.redacted 1.18.0 (Java 21 bytecode), plugin 0.2.8-dev90b (this branch), toolchain .11.1
## hotReloadPackage under JDK 17
91:> CMP hot reload: the project's compiler plugin redacted-compiler-plugin-1.18.0.jar needs Java 21 (class file version 65), but the hot reload compiler runs on Java 17 (<HOME>/.gradle/jdks/eclipse_adoptium-17-aarch64-os_x.2/jdk-17.0.21+9/Contents/Home). Run Gradle with JDK 21 or newer (JAVA_HOME), or point cmpHotReload { daemonJavaHome } at one.
